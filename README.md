# iPhone Mirroring Linux

A Linux port of [iPhone Mirror for Windows](https://github.com/0xCodez/iphone-mirror-windows), based on upstream commit `453a8db`. It uses AirPlay for video and audio and can send input to WebDriverAgent on an authorized iPhone.

The Fedora installation guide, Wi-Fi control setup, and Linux verification will follow in this branch. The Linux port began on November 19, 2026.
